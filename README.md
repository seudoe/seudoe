## Summary

Full-stack developer building across AI agent architectures, developer tooling, and systems programming.

- **Multi-Agent Systems & Web3**: Built **x402-multi-agent-router** (1st Runner Up at AlgoVerse), coordinating task delegation across autonomous agents with atomic micropayments settled via Algorand testnet smart contracts. Exploring LangChain, LangGraph, Model Context Protocol (MCP), and tool-calling workflows.
- **Search & Moderation Pipelines**: Co-architected **iFind** (documented in an IEEE conference paper), a multi-source recruitment platform with a 7-source ingestion pipeline, ML-based scam classification, and sub-millisecond semantic search powered by 768-d BERT embeddings, 15,000-d boosted TF-IDF vectors, and local HNSW graph indexing.
- **Interactive Full-Stack Web**: Built **Pixel Paranoia** using Next.js 16, Three.js, React Three Fiber, GSAP animations, and Supabase for real-time state sync. Developed **Env Manager**, a lightweight full-stack platform for synchronizing `.env` files across environments without runtime dependencies.
- **Developer Tooling**: Author of **[seudoe](https://github.com/seudoe/seudoe)**, a packaged VS Code extension for competitive programming on Codeforces with in-editor KaTeX problem rendering, automatic test-case extraction, local boilerplate generation, and custom compiler runners.
- **Core Systems & Fundamentals**: Working directly with x86/x64 assembly, memory management and data structures in C/C++, network sockets, and database query engines.
